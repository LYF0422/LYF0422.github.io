# 分类记录与陈列

打开 `/studio/`，在标题上方的分类菜单选择记录类型。文字继续使用原来的排版工具；记录卡、照片和 PDF 会和文章一起自动保存、同步到 GitHub。

## Anime / Game

1. 选择 Anime 或 Game，输入作品名称，点击“搜索作品”。支持中文名、原名和别名，也可输入已收录作品的 Bangumi 条目链接或编号。
2. 点击对应结果，自动带入名称、封面、日期、类型、集数以及导演或开发商等资料。空标题会使用作品名。
3. 填写“我的评分”（0–10，支持半分）、进度和简评，在正文中写详细感想。
4. 保持“陈列展示”勾选并发布，分类首页即显示封面、个人评分、进度和简评。点击卡片进入完整博客。取消勾选后，文章仍在普通列表中。

作品库按 Bangumi 收藏人数选取 600 部热门动画和 600 部热门游戏。资料、搜索索引和压缩封面由博客自身提供，不需要访问 Bangumi 或 Cloudflare 中转，也不需要 Bangumi 令牌。搜索框下方显示实际收录数量和更新时间。只有已收录的作品可以关联；搜索不到时可尝试原名或别名，仍未命中则暂未收录，不会自动请求外部接口。

个人评分只保存到自己的博客，不会修改 Bangumi 账号的评分。选择作品时保存资料快照，封面复制为文章附件，随文章一起发布。这样即使作品以后移出热门库，已发布文章仍保留资料和封面。下载封面失败时仍可保存评分与简评，再次选择作品可重试封面。

作品库计划于北京时间每周一 06:17 自动更新（GitHub Actions 可能延迟）。同步失败保留上一版。手动更新和维护方法见 [部署指南](DEPLOYMENT.md#站内热门作品库)。

## Photo

1. 选择 Photo，点击“添加照片”批量选择图片，也可拖入上传区，或在相册面板中粘贴图片。
2. 在每张照片下填写简评，使用 ↑ / ↓ 调整顺序，选择其中一张作为相册封面。
3. 填写相册标题、相册简评；正文可继续写完整游记。
4. 发布后，Photo 首页显示封面和照片数量；相册内按顺序展示照片与简评，点击照片可放大。

照片沿用写作台的压缩规则，处理后的附件和文章在同一个提交中发布。

## Paper Reading

1. 选择 Paper Reading，粘贴论文网址或 PDF 链接，点击“添加论文”。arXiv、OpenReview 和 ACL Anthology 常见论文页面会转换为 PDF 预览地址。
2. 也可以点击“上传 PDF”（单个不超过 20 MB）；PDF 会先保存在本机，发布时写入 `public/documents/studio/`。
3. 可选填写作者和阅读摘要，在正文中写方法、公式、实验结果与想法。电脑上原文和笔记并排，手机上依次排列；“收起预览”可暂时隐藏原文。
4. 如自动识别失败，可手动填写 PDF 链接。某些论文网站禁止网页内嵌，此时可打开原文，或上传 PDF 后站内预览。PDF 预览使用浏览器自带阅读器，不同设备的操作界面可能不同。
5. 发布后，Paper Reading 的陈列卡可进入论文与笔记页，点击“展开阅读”使用更宽的并排排版。

笔记是文章正文，保存在 GitHub，可跨设备继续编辑；公开页面供访客阅读，不开放匿名修改。已公开发布的 PDF 和照片可以通过网站访问。

## 已有文章

已有文章无需修改，普通文章列表保持兼容。在写作台打开已有记录，添加作品、照片集或论文后再次发布，即可加入相应陈列面板。草稿和未来时间的文章遵循原有发布规则。
