# 分类记录与陈列

打开 `/studio/`，在标题上方的分类菜单选择记录类型。文字继续使用原来的排版工具；记录卡、照片和 PDF 会和文章一起自动保存、同步到 GitHub。

## Anime / Game

1. 选择 Anime 或 Game，输入作品名称，点击“搜索作品”。支持中文名、原名和别名，也可输入已收录作品的 Bangumi 条目链接或编号。
2. 点击对应结果，自动带入名称、封面、日期、类型、集数以及导演或开发商等资料。空标题会使用作品名。
3. 填写“我的评分”（0–10，支持半分）、进度和简评，在正文中写详细感想。
4. 保持“陈列展示”勾选并发布，分类首页即显示封面、个人评分、进度和简评。点击卡片进入完整博客。取消勾选后，文章仍在普通列表中。

作品库以 Bangumi 收藏热度为主、评分排名为补充，选取 600 部热门动画和 600 部热门游戏。资料、搜索索引和压缩封面由博客自身提供，不需要访问 Bangumi 或 Cloudflare 中转，也不需要 Bangumi 令牌。搜索框下方显示实际收录数量和更新时间。只有已收录的作品可以关联；搜索不到时可尝试原名或别名，仍未命中则暂未收录，不会自动请求外部接口。

个人评分只保存到自己的博客，不会修改 Bangumi 账号的评分。选择作品时保存资料快照，封面复制为文章附件，随文章一起发布。这样即使作品以后移出热门库，已发布文章仍保留资料和封面。下载封面失败时仍可保存评分与简评，再次选择作品可重试封面。

作品库计划于北京时间每周一 06:17 自动更新（GitHub Actions 可能延迟）。同步失败保留上一版。手动更新和维护方法见 [部署指南](DEPLOYMENT.md#站内热门作品库)。

## Photo

1. 选择 Photo，点击“添加照片”批量选择图片，也可拖入上传区，或在相册面板中粘贴图片。
2. 在每张照片下填写简评，使用 ↑ / ↓ 调整顺序，选择其中一张作为相册封面。
3. 填写相册标题、相册简评；正文可继续写完整游记。
4. 发布后，Photo 首页显示封面和照片数量；相册内按顺序展示照片与简评，点击照片可放大。

照片沿用写作台的压缩规则，处理后的附件和文章在同一个提交中发布。

## Paper Reading

1. 点击“新建记录”，在弹窗选择 Paper Reading，粘贴论文网址或上传 PDF（单个不超过 100 MB）。arXiv、OpenReview 和 ACL Anthology 常见页面会转换为 PDF 下载地址，也支持粘贴 Markdown 链接。
2. 网址导入会下载、检查并缓存 PDF，显示下载进度；内嵌信息不足时尝试从首页识别标题、作者、摘要、年份、DOI 和发表信息；有 DOI 时尝试补充对应会议 / 期刊、出版社及卷期页码。请在弹窗检查结果后创建；自动读取不会覆盖本次手动填写的字段。扫描件需要手动补充，不进行 OCR 或请求外部识别服务。
3. 创建后默认只显示 PDF 和批注，导入表单不占阅读空间。点“独立笔记”可展开正文写方法、公式和实验结果；原有正文保留。右键左侧文章或点“⋯”，选择“修改文章信息…”可修改标题、类型、标签、论文资料或替换 PDF；顶部“修改信息”也可打开相同窗口。修改后发布即可更新网站。
4. 下载的 PDF 先保存在本机，发布时写入 `public/documents/studio/`，以后打开无需再次连接论文网站。“大屏阅读”将 PDF 展开到整个窗口，点“退出大屏”或按 Esc 返回；缩放菜单支持放大到适合宽度的 300%，用页面内滚动条浏览。
5. 选中文字，点击“高亮选文”，可为高亮添加批注。扫描版可点击“框选高亮”，拖动标记图表或文字区域。可选黄色、蓝色或粉色。“位置批注”允许点击页面任意位置添加便签；“页面批注”直接为当前页添加笔记。
6. 删除时，点选页面上的高亮或便签，再点“删除标注”；也可打开阅读器顶部的“批注”列表，使用每张卡片上的“删除”按钮。删除后可点“撤销删除”恢复；刷新页面后不能撤销。点击批注卡的页码可跳转，卡片内可直接修改批注。页码、翻页和缩放位于阅读器顶部，手机也可使用。
7. 批注自动保存在本机，发布时与文章、PDF 附件一起同步到 GitHub。重新打开或跨设备加载文章会恢复批注。批注按文件内容绑定，替换 PDF 时保留旧版本批注；重新上传原文件可恢复显示。批注作为文章数据在网站叠加显示，下载原始 PDF 不包含这些批注。
8. arXiv 优先使用站内缓存；新论文若因网络限制无法直接下载，可点“通过 GitHub 获取”，连接后由仓库任务获取公开 PDF，通常等待 1–3 分钟并自动继续填充。其它来源可下载后上传 PDF。具体错误显示在网址旁，已填写信息保留；取消不会创建文章或改动原文章，已提交的公开论文下载任务可能继续缓存文件。加密或损坏的文件需先处理后上传。
9. 发布后，Paper Reading 的陈列卡可进入论文与笔记页，点击“展开阅读”使用更宽的并排排版，或在 PDF 工具栏中打开“大屏阅读”。访客可以查看作者的高亮和批注、按页定位；编辑在写作台完成。

笔记是文章正文，保存在 GitHub，可跨设备继续编辑；公开页面供访客阅读，不开放匿名修改。已公开发布的 PDF 和照片可以通过网站访问。

## 已有文章

已有文章无需修改，普通文章列表保持兼容。在写作台打开已有记录，添加作品、照片集或论文后再次发布，即可加入相应陈列面板。草稿和未来时间的文章遵循原有发布规则。
